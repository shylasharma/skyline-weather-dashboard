# 🌤️ Skyline Weather Dashboard

A modern **full-stack weather application** built with **React, Vite, Express.js, Open-Meteo API, and OpenStreetMap**. It provides real-time weather updates, hourly forecasts, 7-day forecasts, air quality monitoring, geolocation support, city autocomplete, and an interactive responsive user interface.

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/shylasharma/skyline-weather-dashboard.git
```

### 2. Navigate to the Project

```bash
cd skyline-weather-dashboard
```

### 3. Install Backend Dependencies

```bash
cd backend
npm install
```

### 4. Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

### 5. Start Backend

```bash
cd ../backend
npm run dev
```

### 6. Start Frontend

```bash
cd ../frontend
npm run dev
```

Open:

```
http://localhost:5173
```
